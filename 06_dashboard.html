STEP 4 즉시 결정 사항
P1

Switzerland 데이터 신뢰성 검증

임상팀에 chol=0 원인 규명 요청 (수집 오류? 프로토콜 차이? 단위 변환 오류?). Switzerland 협착 93% 이유 확인 (고위험 선별군 vs 다른 진단 기준?). 결정: Switzerland 포함 vs 제외 → 정확도 변화 재평가.

P1

Cleveland+Hungarian+VA 조합 재평가

Switzerland 제외 후 12개 지표 모델 성능 재계산. 예상 정확도 79~81%, 예상 특이도 75~80% (현재 72.40%에서 개선 추정). 신뢰도 향상으로 배포 판단 가능해짐.

P1

Long Beach VA 모델 재진단

클래스 가중치 조정(class_weight='balanced') 적용 후 재평가. AUROC 0.42 → 0.70 이상 달성 가능 여부 확인. 불가능하면 VA 데이터 별도 수집 및 모델 재훈련 필요.

P2

ca/thal 복구 전략 검토

옵션 1: 결측 보간 — age, oldpeak, thalach 등으로 ca/thal 예측 모델 구축. 옵션 2: 도메인 전문가 지식 활용 — 임상팀이 ca/thal 보정값 제시 가능한지 확인. 옵션 3: 신규 임상 데이터 수집 — Cleveland에서 ca/thal 완전 데이터 추가 수집. 목표: ca/thal 손실 2.55%p 회복으로 83% 정확도 달성.

P2

병원별 배포 전략 수립

Cleveland 환자 대상: Cleveland 12개 지표 모델 (77.90%, 안정적). 협착 고위험 병원(VA처럼 협착 80% 이상): 다국가 모델 또는 민감도 우선 모델. 협착 저위험 병원(Hungarian처럼 협착 40% 이하): Cleveland+Hungarian 조합 모델 (고 특이도). 신규 병원: 협착 비율 파악 후 적절한 모델 선택 가이드라인 제시.

P3

외부 검증 데이터 수집 계획

5-fold CV는 과적합 위험. 독립적인 테스트셋 (서로 다른 병원의 신규 환자) 필요. 각 병원별로 모델 성능 재검증 (Hold-out validation).

주의 이 결론이 틀렸다면

기저율 효과와 정확도의 분리

다국가 모델 80.60% 정확도 중 약 2.5%p는 "협착이 많은 데이터에 맞춤"(기저율 효과)이고, 약 0.2%p만 실제 모델 성능 개선입니다. Cleveland(협착 46%)에 이 모델을 적용하면 77~78% 정확도로 저하 예상. 반대로 Switzerland(협착 93%)에 적용하면 85% 이상으로 상승하지만 특이도는 극도로 저하됩니다.

표본 크기와 신뢰도

다국가 통합(n=531)이 Cleveland 단독(n=303)보다 표본이 1.75배 많지만, Swiss의 데이터 품질 문제와 VA의 극도 불균형 때문에 신뢰도는 오히려 낮습니다. 표본 크기는 필요조건이지 충분조건이 아닙니다.

5-fold CV의 한계

현재 평가는 Hold-out test가 아니라 5-fold Cross-Validation입니다. 신규 환자 데이터 추가 시 성능이 보장되지 않으며, 특히 Switzerland/VA처럼 분포가 극도로 다른 데이터는 CV 안에서도 신뢰도가 낮습니다. 독립 테스트셋 검증이 필수입니다.

지표 정의

정확도 (Accuracy): (TP + TN) / (TP + TN + FP + FN) — 전체 예측 중 올바른 예측의 비율

민감도 (Sensitivity/Recall): TP / (TP + FN) — 협착 있는 환자 중 올바르게 진단된 비율 (협착 환자 놓침 최소화)

특이도 (Specificity): TN / (TN + FP) — 협착 없는 환자 중 올바르게 진단된 비율 (정상인 오진 최소화)

PPV (양성예측도): TP / (TP + FP) — 협착 있다고 진단한 경우 실제로 협착이 있을 확률

NPV (음성예측도): TN / (TN + FN) — 협착 없다고 진단한 경우 실제로 협착이 없을 확률

AUROC: ROC 곡선 아래 면적 (0.5=무작위, 0.85 이상=우수, 0.90 이상=매우 우수)

제외조건: Cleveland 14개는 ca/thal 결측 6행 제외(n=297). Cleveland 12개는 ca/thal 의도적 제외(n=303). 다국가 12개는 병원별 결측 제외 후 합계(n=531). Switzerland는 협착 97.8%로 5-fold CV 일부 fold에 클래스 부족.
