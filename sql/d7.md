rating_count	그 상품에 달린 전체 리뷰 개수 (많을수록 인기/신뢰도 높음)
ORDER BY rating_count DESC (여기서)	중복된 행 중 "리뷰 개수가 더 많이 쌓인 쪽" = "더 최신 데이터"를 1등으로 세우기 위함
결과적 효과	중복 제거 시 임의로 아무거나 남기는 게 아니라, 근거 있게 최신 데이터를 남김

중복 제거 
SELECT *,
       ROW_NUMBER() OVER (PARTITION BY product_id ORDER BY rating_count DESC) AS rn
FROM df

밖에 쿼리에서
WHERE rn = 1 : 1층에서 매긴 번호를 보고 중복 제거. 1465행 → 1351행
